# MoviGO

Repositorio multiproyecto. La app Flutter vive en `movigo_flutter/`.

## Flutter (MoviGO)

Ruta: `movigo_flutter/`

### Requisitos
- Flutter SDK
- Android Studio (Android) / Xcode (iOS)

### Ejecutar
```bash
cd movigo_flutter
flutter pub get
flutter run
```

### Release
```bash
cd movigo_flutter
flutter build apk --release
# o
flutter run --release -d <deviceId>
```
